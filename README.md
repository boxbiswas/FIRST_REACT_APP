# MoviesHub

A small React app for searching movies.

## Scripts

- `npm start` - start the Vite dev server
- `npm run dev` - same as start
- `npm run build` - create a production build
- `npm run preview` - preview the production build locally

## Notes

This project now uses Vite instead of Create React App, which removes the old react-scripts dependency tree and gives much cleaner install output.
